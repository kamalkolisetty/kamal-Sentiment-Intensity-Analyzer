🚀 From a Basic Sentiment Tool to an Intelligent Tone & Emotion Analyzer

🎯 What is Sentiment Intensity Analyzer?

This is an advanced AI-powered web application designed to understand not just whether text is positive or negative, but to deeply analyze the emotional intensity 😢😡 and underlying tone 😏 of any written text. Whether it's casual GenZ chat, customer feedback, professional emails, or angry complaints — this tool helps users truly understand the emotion and intent behind the words.

📖 Our Complete Journey

We started this project with a very basic Flask web app using the cardiffnlp/twitter-roberta-base-sentiment model. It could only detect Positive, Neutral, or Negative sentiment with some hardcoded motivational messages. However, we quickly realized it was quite limited and often inaccurate on real-world text — especially sarcasm, mixed emotions, commands, grief, and passive-aggressive messages.

So we began a long journey of experimentation. We tried multiple models, tested them rigorously with difficult examples, removed the ones that were not performing well, and finally kept only the strongest two models. This iterative process helped us build a much more reliable and useful tool.

🧠 Our Final Powerful Models
🎭 1. Emotion Detection Model

Model: j-hartmann/emotion-english-distilroberta-base
Developed by: Jan Hartmann
Architecture: DistilRoBERTa (lighter & faster version of RoBERTa)
Training Data: Combination of 6 diverse English emotion datasets (~20,000 balanced examples)
Detects Emotions like : Anger 😡, Joy 😊, Sadness 😢, Fear 😱, Surprise 😲, Disgust 🤢, Neutral 😐

We show you the Top 7 emotions with percentage scores so you can clearly see the emotional intensity of any text.

🔍 2. Zero-Shot Tone Analysis

Model: facebook/bart-large-mnli
Developed by: Facebook AI (Meta)
Architecture: BART-Large
Training Data: MultiNLI (MNLI) dataset — ~433,000 sentence pairs for Natural Language Inference
Can Understand Many Tones: Sarcastic 😏, Threatening 💀, Angry 😠, Polite 🙏, Rude 😤, Disappointed 😞, Encouraging 🌟, Professional 💼, Casual 😂, and more...

We show you the Top 7 tones with confidence scores. This model is especially powerful at catching sarcasm and hidden intent!

🔄 Evolution of the Project
  • Started with basic 3-label sentiment analysis
  • Added multiple models (Sentiment + Stars + Formality + Emotions)
  • Conducted extensive testing on real challenging inputs (sarcasm, grief, commands, mixed emotions)
  • Removed weak performing models after careful evaluation
  • Focused only on the two best models for accuracy and speed
  • Built a modern, beautiful, and engaging user interface with animated gradients and floating emojis
